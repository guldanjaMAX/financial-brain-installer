## Owner answer acceptance

Every owner question must receive the best answer supported by the available
records. A refusal or a wrong figure at High confidence blocks release.
The data sets the confidence score and the assistant may only lower it.
Each answer must show the confidence label and percent. Below 100%, it must
explain why and name the missing evidence. Check the figure and period
first, account and date coverage, missing or double-counted dollars, estimates
and their basis, and how to check.

On the exact final package, verify fresh bank balances and repeat the check
with a failed bank read and with an unusable receipt. Compare supported amounts
with independent truth and confirm that an unverified balance is identified.
Verify recent activity after the feed asks for a smaller window. Miss one
scheduled Drive run and verify that the next daily run catches up. Connect
Claude with incomplete source coverage and a missing answer-route receipt.
Confirm money tools respond, the working link stays connected, and answer-route
proof stays pending. Repeat with money tools deliberately unavailable.

Known limits to account for during verification.

- Review of the inherited Claude route check found that projection catch-up
  can still bypass the money probe and that valid timing can be accepted even
  when the answer is withheld or incomplete.

- Rolling back an empty partial replacement poll can leave its resume action
  unavailable (review B08).
- Older Brain commands using the shared Windows lock folder can run outside
  the private per-user lease.
- SimpleFIN evening purchases may land on the next UTC day.
- A Drive folder with an unexpected Google trash flag can settle a file inside
  it as outside the watched folders. A refused Drive restore can lose its
  error record across runs while its restore obligation stays open. Both
  limits carry forward from 0.4.33.

Acceptance reads the Worker's own explanation fields. Audit each supported
figure against independent truth.
