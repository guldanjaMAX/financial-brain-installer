Financial Brain per-user application removal

Use Windows Settings > Apps > Installed apps and uninstall the named Financial
Brain version. Each version has its own entry and Start-menu setup shortcut.
Older application versions remain installed until explicitly removed.

Native uninstall removes that version's registered application files and its
shortcut. It removes empty application directories only. Unknown extra files
remain visible for review; uninstall does not recursively erase a directory.

Owner state under LocalAppData\FinancialBrain, the manifest and documents under
the owner's Financial Brain folder, .brain state, OAuth records, credentials,
provider resources and Brain data are preserved. Removing an application is
not permission to delete a Brain or revoke its credentials.

The private runtime and npm have no global installation and no PATH change.
The review build is unsigned. Signing, signed browser-download SmartScreen,
and clean-VM first-open remain release gates for MAIN.
